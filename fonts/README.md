# Fonts

Bundled so the game works offline. All four are free under the SIL Open Font License 1.1 (the license text for each is in this folder), taken from the Fontsource packages (latin subsets).

| Font | Used for |
| --- | --- |
| Cinzel | Titles and headings (letterforms based on Roman inscriptions) |
| EB Garamond | Story text |
| Pinyon Script | Velati journal headings only |
| OpenDyslexic | The "Dyslexia friendly" story font setting |

The service worker pre-caches the first three; OpenDyslexic is cached the first time it is used.
