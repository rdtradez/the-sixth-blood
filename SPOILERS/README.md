# SPOILERS

Chapter plans for each book are written here, one file per book, before the chapters are built. The owner does not open this folder, so nothing here appears in chat, reports or commit messages.

`book-1.md` holds the Book One notes, starting with the prologue.

`blood-and-gold.md` holds the Book Two notes.

`crown-of-ashes.md` holds the Book Three notes.

`house-divided.md` holds the Book Four notes.

Standing rules for every chapter plan: a coven member is in the chapter's main thread; scenes call on the family's gifts; named members are always checked with `in_circle()`; each book opening has the business lead's report and desk, and a village letter.
