# The Sixth Blood

A choice game in seven books, played in the browser and installable as an app.

- Play: enable GitHub Pages for this repo (Settings, Pages, deploy from `main`, root folder) and open the Pages URL on your phone.
- Develop: `npm test`, `npm run check`, `npm run walk` (branch explorer), and serve the folder with any static server.
- Build notes: `DESIGN.md`. Writing format: `docs/SCRIPT_FORMAT.md`. Saves: `docs/SAVES.md`. Game systems: `docs/SYSTEMS.md`.
